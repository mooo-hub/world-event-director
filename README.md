# 世界事件导演

世界事件导演是一个 SillyTavern（酒馆）扩展，让角色扮演聊天里偶尔发生一些符合剧情的意外。比如，你和角色正在商量出门，窗外突然下起大雨。到了合适的时机，插件会把这件事作为提示交给聊天模型，由聊天模型在下一条角色回复中写进故事。

每个聊天和分支各自保存事件库。生成事件时会使用部分聊天和设定资料，详见下文。

当前版本为 **0.3.0-rc.5**（候选版）。

## 安装

### 通过 Git 链接安装（推荐）

1. 在酒馆打开 **扩展 → 安装扩展程序**。
2. 粘贴下面的仓库地址。

   ```text
   https://github.com/mooo-hub/world-event-director.git
   ```

3. 安装完成后刷新酒馆页面，在扩展面板中展开 **世界事件导演**，也可以点聊天输入框旁的地球图标。


## 插件会读取哪些内容？

生成事件时，插件会参考当前聊天里的这些资料。

- **角色卡和用户人设**：角色名称、描述、性格、场景、对话示例、作者备注、角色卡中的提示词和扩展资料，以及当前用户人设的名称和描述。
- **聊天预设**：酒馆提供的当前预设中已启用的提示词正文。
- **世界书**：全局启用的世界书，绑定到当前角色、当前聊天或当前用户人设的世界书，以及角色卡内嵌的世界书。禁用或没有正文的条目会跳过。
- **聊天消息**：当前聊天最近最多 30 条消息。插件也会根据聊天和设定整理当前场景，例如地点和在场角色。

插件会自行挑选供事件模型参考的世界书条目，例如常驻条目、备注含「规则」的条目，以及关键词出现在近期聊天或与当前场景有关的条目。酒馆这一轮没有触发的条目，也可能被选中。识别为记忆摘要的条目会另作参考。

**生成事件时，选中的资料会随请求发给你在「模型连接」中配置的事件生成服务。** 内容太长时，插件会尝试缩减请求，例如省略优先级较低的世界书条目和较早的消息。

切换世界书或修改设定后，可以在插件面板点 **重新同步上下文**，并在 **同步状态** 查看已同步的世界书和条目数量。

## 第一次使用

1. 打开一个角色的聊天，进入插件的 **模型连接** 页。
2. 选一个支持 OpenAI 兼容接口的模型服务，在这里填入服务商提供的 **API Base URL**（接口地址）、**API Key**（访问密钥）和**模型名称**。模型名称可以手动填，也可以点 **拉取列表** 后选择。生成事件的模型单独在这里设置，角色回复仍用酒馆当前的聊天模型。
3. 连接方式先选 **直连**。点 **测试连接** 确认服务能回复，再点 **保存设置**。保存后，符合条件的聊天可能会自动开始首次生成。
4. 打开 **事件库** 查看结果。如果没有开始生成，可以点 **重新生成事件**。有了候选事件后，照常聊天即可。

## 日常使用

- **什么时候会触发？** 默认每 5 轮对话尝试抽取一次。事件还要符合当前场景和触发概率，所以检查时也可能没有事件。想调整频率，可以打开 **设置** 修改间隔。
- **想换一批？** 点 **重新生成事件**。当某轮有新事件通过检查时，就会切换到新一批，剩余条数继续补到 5 条。如果一条新事件都没通过，旧库会保留。
- **想保留现有事件？** 不足 5 条时点 **补足事件**，原有事件会保留。自动更新也会先补足。当前一批全部发生且对应的聊天回复正常结束后，插件会在之后的检查中尝试换批。
- **怎么看进展？** 事件库会标出状态。**已生成**表示事件已准备好，**待插入**表示已选中、等下一次回复，**已发生**表示插件已确认事件提示放进了聊天模型的请求。生成清单时，进度区会显示每轮耗时、通过条数和失败原因。合格事件在当轮结束后就会显示。
- **想改某一条？** 在 **事件库** 里打开事件卡片，点击 **编辑** 或 **删除**。编辑时会看到带字段的文本（JSON），改完后点 **保存事件**。
- **想暂时停用？** 在 **设置** 关闭 **启用事件导演**。影响特别强的事件默认不会自动触发。

## 生成失败怎么办？

每次尝试最多等待 90 秒，一次生成最多尝试 4 次。短连接测试成功只表示服务能回复简单请求，生成整批事件可能花更久。如果进度反复显示等待服务响应超时，可以用响应较快的模型再试。已经通过检查并显示的事件会保留。

如果浏览器无法直连模型服务，可以按需安装本地代理，让酒馆代为转发请求：

1. 将仓库中的 `server-plugin/` 复制到酒馆的 `plugins/world-event-director/`。
2. 在酒馆的 `config.yaml` 中设置 `enableServerPlugins: true`，并在 `plugins/world-event-director/` 目录运行 `npm install`。
3. 重启酒馆，在 **模型连接** 中将连接方式改为 **本地代理**，测试连接并保存。
